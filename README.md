# Морской бой

![C++](https://img.shields.io/badge/C%2B%2B-20-00599C?logo=cplusplus)
![SFML](https://img.shields.io/badge/SFML-2.6.x-8CC445)
![Platform](https://img.shields.io/badge/platform-Windows-0078D4?logo=windows)

Учебная реализация классического «Морского боя» против компьютерного
соперника. Игра автоматически размещает флоты, отображает два поля 10 × 10 и
передаёт ход между игроком и ИИ после промаха.

## Возможности

- стандартный флот из десяти кораблей длиной от одной до четырёх клеток;
- автоматическая расстановка кораблей без соприкосновений;
- выстрелы мышью и визуальное отображение попаданий, промахов и потоплений;
- ИИ с режимом добивания раненого корабля;
- вероятностная карта для выбора перспективной клетки;
- пятисекундная задержка перед ходом компьютера;
- отдельные классы игрового поля, ИИ и отрисовки.

## Управление

- **ЛКМ по правому полю** — выстрелить;
- **крестик окна** — завершить игру.

После попадания игрок продолжает стрелять. После промаха ход переходит к
компьютеру. Игра заканчивается, когда уничтожен весь флот одной из сторон.

## Архитектура

| Файл | Назначение |
|---|---|
| `Game.*` | игровой цикл, ввод и смена хода |
| `Board.*` | клетки, корабли, выстрелы и проверка победы |
| `AIController.*` | стратегия компьютерного игрока |
| `ProbabilityMap.*` | расчёт вероятностей размещения оставшихся кораблей |
| `Renderer.*` | отрисовка полей и состояния клеток |
| `GameConfig.h` | размеры поля, окна и состав флота |

## Требования

- Windows 10/11;
- Visual Studio 2022 с компонентом **Разработка классических приложений на C++**;
- CMake 3.20 или новее — для альтернативной сборки;
- SFML 2.6.x для x64.

## Сборка в Visual Studio

Проект Visual Studio настроен на SFML 2.6.1 в каталоге
`C:\IT\SFML-2.6.1-windows-vc17-64-bit\SFML-2.6.1`. Если библиотека находится
в другом месте, измените пути в свойствах проекта:

1. Откройте `battleship.sln`.
2. Выберите конфигурацию **x64** и `Debug` либо `Release`.
3. В свойствах проекта укажите свои каталоги `SFML/include` и `SFML/lib`.
4. Соберите решение сочетанием `Ctrl+Shift+B`.

## Сборка через CMake

```powershell
cmake -S . -B build -A x64 `
  -DSFML_DIR="C:/Libraries/SFML/lib/cmake/SFML"
cmake --build build --config Release
./build/Release/BattleshipGame.exe
```

Файл `arial.ttf` копируется рядом с программой автоматически.
